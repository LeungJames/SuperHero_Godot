# 制作方向路线图（Vision Roadmap）

> 独立文件，不替代 [superhero.md](./superhero.md)（长期愿景）与 [superhero-design.md](./superhero-design.md)（施工说明）。
> 本文只回答三个问题：**接下来可以做什么、为什么值得做、代价有多大**。已有的设定、数值与实现细节不在这里重复。

---

## 0. 范围判断

先看现状：

- 已有**两个章节**
- 已有**五把枪**的规划与解锁节奏
- 已有**角色动画管线**
- 已有**处决与帮派变体**的计划

这个范围已经不小了。继续往上叠系统，边际收益会快速下降：新增的每一把枪、每一种敌人、每一个关卡，都要和"零回血 + 高致命性 + 纵向下行"这套已经很紧的约束重新对齐，平衡成本远高于新增内容本身。

**所以下一步的判断是：先不加系统，先把已有内容打磨到"陌生人能坐着玩二十分钟不劝退"。**

这个标准可以拆成三条可观察的信号：

1. 二十分钟内，玩家不需要问"我现在该干嘛"。
2. 二十分钟内，玩家不会因为手感、信息缺失或卡关而主动退出。
3. 二十分钟结束后，玩家能说出至少一个"想再来一次"的理由。

下面的五个方向按**投入产出比**排序，而不是按"想做程度"排序。

| 优先级 | 方向 | 可玩性提升 | 新增资产负担 | 风险 |
| --- | --- | --- | --- | --- |
| 1 | 战斗手感与敌人协同 | 高（三个关卡同时受益） | 几乎为零 | 中 |
| 2 | 潜行路线深度 | 高（重玩价值） | 低 | 中高 |
| 3 | 叙事与演出 | 中（情绪与记忆点） | 低 | 低 |
| 4 | 完成度与可交付 | 高（决定能否给别人玩） | 零 | 中 |
| 5 | 内容量 | 中（新鲜感） | 高 | 高 |

---

## 一、战斗手感与敌人协同

**现状**

敌人各自为战：会巡逻、会找掩体、会压制，但彼此之间没有配合。三个敌人站在一起，实际体验是"三个独立的麻烦"，而不是"一支队伍"。玩家很容易靠逐个击破把战斗拆成三次单挑。

**目标体验**

让敌人形成战术分工，让玩家感觉自己是在对抗一支队伍：

- 一人负责压制（保持距离、持续火力、逼玩家缩在掩体后）
- 一人负责包抄（利用侧翼路线绕到玩家背后）
- 一人受伤后主动后撤、换位、由同伴接替火力
- 同一个小队共享"玩家在哪"的情报，但不同小队之间不共享

这不需要玩家学新操作，纯粹改变敌人的行为组织方式。

**主要工作内容**

1. **小队编制**：给敌人加"小队"归属（一个队长 + 1–2 名成员），关卡里按小队布置，而不是按单个敌人布置。
2. **角色槽位**：小队内分配"压制 / 包抄 / 支援"三个槽位，随人数与地形动态调整。
3. **共享感知**：小队内共享最后已知位置与警戒等级；跨小队仍然独立（保持现有设计）。
4. **交战节奏控制**：同屏真正开火的敌人数量受控，其余做移动与掩护，避免"零回血"下被集火秒杀。
5. **后撤与掩护**：受伤敌人退到掩体后，由同伴提供压制；退无可退时才死战。
6. **可调试**：给 AI 加可视化（当前状态、目标点、槽位、共享情报范围），否则协同 bug 很难定位。
7. **行为提示**：用无线电短句或漫画拟声词提示"有人绕后"，让玩家能读懂协同，而不是被莫名其妙地打死。

**是否需要新素材**

不需要。现有两种敌人行为（街头枪手 / 守卫）正好可以充当"包抄"与"压制"的基底，帮派只是换皮与参数差异。

**工作量**

中。改动集中在 AI 调度层与关卡敌人布置，不涉及美术、不涉及武器、不涉及新场景。

**风险**

- 协同容易写成"三个人一起冲脸"，反而更单调：必须有节奏控制与槽位约束。
- 零回血下，包抄一旦成功就是必死：包抄路线必须可被玩家提前发现（声音、影子、无线电提示）。
- AI 状态机叠加容易产生卡死：需要可视化调试与超时兜底（卡住超过 N 秒自动回到巡逻）。

## 二、潜行路线深度

**现状**

暗杀与环境击杀（爆炸桶）已经有了，但每关只有一条潜行路径。玩家要么全程潜行、要么正面强攻，中间没有真正的选择。

**目标体验**

每关都能"全潜行打通"与"正面强攻"两种截然不同的玩法：

- 全潜行：不触发警报、逐个处理哨位、利用环境击杀，最后无声清场
- 正面强攻：警报拉响、敌人增援、靠枪法与掩体硬吃
- 中途失败可以"软回落"：被发现不等于重开，可以撤退、切断追击、重新潜行

**主要工作内容**

1. **第二条潜行路径**：每关增加一条不经过主交火区的支路（通风管、脚手架外侧、集装箱背面），与主线在关键节点汇合。
2. **哨位重排**：把现有巡逻点重新组织成"可被绕开"和"必须处理"两类，让玩家做取舍。
3. **警报分级**：从"发现即全场增援"改为"局部警戒 → 搜索 → 升级增援"的三级，给玩家脱离的空间。
4. **藏尸与痕迹**：尸体被发现会提升警戒；提供藏尸点或至少让玩家能把尸体拖进阴影。
5. **潜行反馈**：警戒指示（敌人头顶的疑问/感叹、声音提示），让潜行状态可读。
6. **近战暗杀的可用性**：港口章节的武器池只有手枪与近战，潜行暗杀正好落在近战上，不需要额外武器。

**是否需要新素材**

少量，且大部分可复用：通风管口、可藏身的箱体、阴影体积、警戒图标。不需要新角色、不需要新枪。

**工作量**

中到大，成本主要集中在关卡设计与敌人巡逻重排，代码改动小于方向一。

**风险**

- 与"零回血"天然冲突：潜行失败一次可能就直接死亡。警报分级与脱离机制是必需品，不是可选项。
- 全潜行通关如果太容易，正面强攻就失去意义；需要用"潜行耗时更长、容错更低"来平衡。
- 两条路径都要保证导航连通与敌人不卡死，关卡验证成本会翻倍。

## 三、叙事与演出

**现状**

已经建立的风格是无线电通讯加漫画化拟声词。这套语言很轻，但还没有被用来讲一个具体的故事。

**目标体验**

让玩家在打完之后能记住一两个画面或一句话，而不是只记得"打完了"。

可延伸的方向：

- **环境叙事**：墙上的帮派涂鸦、散落的报纸、遗留物（工牌、照片、对讲机），用物件说明三方势力在这座港口的关系。
- **过场镜头**：章节开场与结束的短镜头，用漫画分格 + 定格画面，而不是长动画。
- **Boss 战演出**：Boss 登场、阶段转换、死亡时的漫画化定格与拟声词。

**主要工作内容**

1. 三个帮派的视觉符号系统（涂鸦、颜色、口号），复用现有色板。
2. 环境叙事物件的摆放规范与文案（每条不超过两行）。
3. 3–5 个短过场：章节开场、章节结束、Boss 登场、Boss 死亡。
4. 无线电台词库：按战况触发（发现、包抄、求援、撤退、清场）。
5. 漫画化演出组件：分格边框、拟声词贴图、定格 + 抖动，全部走 UI 层，不改 3D 管线。

**是否需要新素材**

低。过场用现有低模 + 定格 + UI 分格实现；音效继续走程序生成，不引入外部素材。

**工作量**

中。主要是文案、分镜与 UI 组件的组合，代码量不大。

**风险**

- **与快速重开的节奏冲突**：玩家会死很多次，同一个过场看第二遍就会烦。规则应是：首次触发播放，之后自动跳过；玩家死亡不触发长演出。
- 叙事容易和玩法脱节：所有台词都要能解释玩家当下的处境，否则就是噪音。
- 三个帮派的设定必须一致，不能出现"这一关是盐帮、台词却在说赤蛇"的错误。

## 四、完成度与可交付

**现状**

没有设置菜单、没有手柄支持、没有存档与章节选择、没有难度选项，同屏人数也没有专门做过性能验证。现在的状态是"自己能玩"，还不是"能给别人玩"。

**目标体验**

把工程从"开发中的原型"变成"可以发给别人试玩的东西"：

- 第一次启动就能改灵敏度、音量、画质
- 手柄插上就能玩
- 退出游戏后进度还在，能选章节重玩
- 有难度选项，且难度不破坏"零回血"的设定

**主要工作内容**

1. **设置菜单**：灵敏度（含 ADS 系数）、音量（主/音效/环境）、画质（阴影、抗锯齿、雾）、全屏与分辨率。
2. **输入重绑定**：键鼠与手柄都支持，配置可保存。
3. **手柄支持**：移动、视角、开火、瞄准、换弹、跳跃、冲刺、暂停；UI 焦点导航。
4. **存档与章节选择**：保存"已通关章节 / 最佳用时 / 设置"，不保存单局中途状态。
5. **难度选项**：只能调敌人反应时间、命中散布、同时交战人数、弹药补给量，**不能调回血**。
6. **性能与同屏人数**：确定 1080p / 60fps 下能稳定承载的敌人数，必要时做 LOD、合批与音频通道限制。

**是否需要新素材**

不需要。

**工作量**

中到大。单项都不难，但覆盖面广，且会和现有的"重开即全量重置"逻辑冲突，需要先把"单局状态"与"持久进度"分开。

**风险**

- 存档与 `ReloadCurrentScene` 的全量重置逻辑冲突：需要明确哪些数据跨场景保留。
- 难度选项很容易滑向"调血量/回血"，这会直接破坏已确认的零回血设定，必须用敌人侧参数实现。
- 手柄的瞄准手感需要单独调曲线，不能直接沿用鼠标灵敏度。

## 五、内容量

**现状**

两个章节已经能撑起一次完整体验，但重复游玩的驱动力有限。

**可选方向**

- **第三章·铁锚据点**：新帮派、新场景、霰弹枪与狙击枪登场、Boss 战。
- **独立短篇试玩章节**：20 分钟内可通关的封闭体验，用来对外展示，不影响主线节奏。

**目标体验**

给玩家"还有新东西"的理由；或者给外部试玩者一个低门槛入口。

**主要工作内容**

- 新关卡与场景套件（码头的另一种面貌：船坞、修船厂、货舱）
- 铁锚帮的行为差异（利用地形、包抄、陷阱）
- 两把新枪的数值、动画、音效与关卡适配
- Boss 的行为、阶段与演出
- 新关卡与"零回血 + 纵向下行"的平衡重做

**是否需要新素材**

高。新场景套件、敌人变体、两把武器、Boss 模型，是五个方向里资产负担最重的。

**工作量**

大。是前四个方向里任意一个的数倍。

**风险**

- **在系统还没打磨好之前扩内容，等于把现有问题复制到新关卡**。
- 新武器会打破现有平衡（尤其是狙击枪与零回血的组合），需要重新验证全部关卡。
- 新场景的美术工作量会挤压打磨时间，容易做成"更长的半成品"。

---

## 六、所有方向都必须遵守的约束

无论选哪个方向，下面几条不能破：

1. **玩家全程不能回血**：没有自动回血、没有医疗包、没有治疗技能。难度与成长只能从敌人强度、弹药、机动与信息入手。
2. **港口章节只有手枪与近战（枪托/刀）**：其它枪械按章节解锁，不能提前出现在港口。
3. **三个帮派的行为差异要成立**：盐帮协同、赤蛇会压上、铁锚帮用地形；不能只是换皮。
4. **尽量零外部依赖**：音效程序生成，模型 Blender 自制，不引入需要授权的素材。
5. **每次改动都要过"二十分钟陌生人试玩"这一关**：不能让已有体验退化。

---

## 七、推荐

**如果只挑一项，选"战斗手感与敌人协同"。**

理由很直接：

- 它不增加任何资产负担，只是重新组织已有敌人的行为。
- 它同时提升三个关卡的可玩性，而不是只让一个新关卡变好。
- 它直接解决当前最明显的问题——敌人各自为战。
- 它是后续内容的地基：潜行的"哨位协同"、Boss 的"阶段配合"、新帮派的"行为差异"，都建立在同一套小队调度之上。

**如果挑两项**：敌人协同 + 完成度（设置菜单 / 手柄 / 存档）。前者让游戏变好，后者让别人能玩到它。

**暂时不建议先做内容量**。在协同、潜行与完成度没有到位之前，第三章只会是一个更长、更贵、问题一样的版本。
