# SuperHero 2.0版本规划

## 目标

不增加新的关卡，在已有的三个关卡上继续打磨，做出更好的效果

## 新增内容

### 一、战斗手感与敌人协同

**目标体验**

让敌人形成战术分工，让玩家感觉自己是在对抗一支队伍：

- 一人负责压制（保持距离、持续火力、逼玩家缩在掩体后）
- 一人负责包抄（利用侧翼路线绕到玩家背后）
- 一人受伤后主动后撤、换位、由同伴接替火力
- 同一个小队共享"玩家在哪"的情报，但不同小队之间不共享

这不需要玩家学新操作，纯粹改变敌人的行为组织方式。

**主要工作内容**

1. **小队编制**：给敌人加"小队"归属（一个队长 + 1–2 名成员），关卡里按小队布置，而不是按单个敌人布置。
2. **角色槽位**：小队内分配"压制 / 包抄 / 支援"三个槽位，随人数与地形动态调整。
3. **共享感知**：小队内共享最后已知位置与警戒等级；跨小队仍然独立（保持现有设计）。
4. **交战节奏控制**：同屏真正开火的敌人数量受控，其余做移动与掩护，避免"零回血"下被集火秒杀。
5. **后撤与掩护**：受伤敌人退到掩体后，由同伴提供压制；退无可退时才死战。
6. **可调试**：给 AI 加可视化（当前状态、目标点、槽位、共享情报范围），否则协同 bug 很难定位。
7. **行为提示**：用无线电短句或漫画拟声词提示"有人绕后"，让玩家能读懂协同，而不是被莫名其妙地打死。

### 二、潜行路线深度

**现状**

暗杀与环境击杀（爆炸桶）已经有了，但每关只有一条潜行路径。玩家要么全程潜行、要么正面强攻，中间没有真正的选择。

**目标体验**

每关都能"全潜行打通"与"正面强攻"两种截然不同的玩法：

- 全潜行：不触发警报、逐个处理哨位、利用环境击杀，最后无声清场
- 正面强攻：警报拉响、敌人增援、靠枪法与掩体硬吃
- 中途失败可以"软回落"：被发现不等于重开，可以撤退、切断追击、重新潜行

**主要工作内容**

1. **第二条潜行路径**：每关增加一条不经过主交火区的支路（通风管、脚手架外侧、集装箱背面），与主线在关键节点汇合。
2. **哨位重排**：把现有巡逻点重新组织成"可被绕开"和"必须处理"两类，让玩家做取舍。
3. **警报分级**：从"发现即全场增援"改为"局部警戒 → 搜索 → 升级增援"的三级，给玩家脱离的空间。
4. **藏尸与痕迹**：尸体被发现会提升警戒；提供藏尸点或至少让玩家能把尸体拖进阴影。
5. **潜行反馈**：警戒指示（敌人头顶的疑问/感叹、声音提示），让潜行状态可读。
6. **近战暗杀的可用性**：港口章节的武器池只有手枪与近战，潜行暗杀正好落在近战上，不需要额外武器。

### 三、叙事与演出

**现状**

已经建立的风格是无线电通讯加漫画化拟声词。这套语言很轻，但还没有被用来讲一个具体的故事。

**目标体验**

让玩家在打完之后能记住一两个画面或一句话，而不是只记得"打完了"。

方向：

- **环境叙事**：墙上的帮派涂鸦、散落的报纸、遗留物（工牌、照片、对讲机），用物件说明三方势力在这座港口的关系。这些物品用于收集，玩家在主菜单，游戏内的菜单能看到收集到的物品，物品的文案用于补充情节
- **过场镜头**：章节开场与结束的短镜头，用漫画分格 + 定格画面，而不是长动画。
- **Boss 战演出**：Boss 登场、阶段转换、死亡时的漫画化定格与拟声词

**主要工作内容**

1. 三个帮派的视觉符号系统（涂鸦、颜色、口号），复用现有色板。
2. 环境叙事物件的摆放规范与文案（每条不超过两行）。
3. 3–5 个短过场：章节开场、章节结束、Boss 登场、Boss 死亡。
4. 无线电台词库：按战况触发（发现、包抄、求援、撤退、清场）。
5. 漫画化演出组件：分格边框、拟声词贴图、定格 + 抖动，全部走 UI 层，不改 3D 管线。

### 四、天赋系统

玩家拥有以下维度的天赋：战术机动、武器大师、忍杀
这四个维度可以各自加点，互不影响。但加点所用的资源不一样
有以下方向：
战术机动：减少蹬墙跑的下滑速度，让玩家能持续在墙面跑；增加钩锁；空中冲刺，玩家可以跳到另一面墙继续蹬墙跑；二段跳；子弹时间
武器大师：枪械子弹扩容；快速换弹；快速切枪；
忍杀：鼓励玩家使用近战武器；随等级提高，挥刀速度更快。能够远距离跳跃处决，格挡子弹；激光剑气远程攻击

### 五、武器库

为了给玩家重复体验，对已经通关过的关卡，可以在关卡开始时选择两把已解锁武器（包含刀）。

### 六、完成度与可交付

**主要工作内容**

1. **设置菜单**：灵敏度（含 ADS 系数）、音量（主/音效/环境）、画质（阴影、抗锯齿、雾）、全屏与分辨率。
2. **输入重绑定**：键鼠与手柄都支持，配置可保存。
3. **手柄支持**：移动、视角、开火、瞄准、换弹、跳跃、冲刺、暂停；UI 焦点导航。
4. **存档与章节选择**：保存"已通关章节 / 最佳用时 / 设置"，不保存单局中途状态。
5. **难度选项**：只能调敌人反应时间、命中散布、同时交战人数、弹药补给量，**不能调回血**。
6. **性能与同屏人数**：确定 1080p / 60fps 下能稳定承载的敌人数，必要时做 LOD、合批与音频通道限制。
