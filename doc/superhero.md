# SuperHero

## 项目概述

### 1.1 核心定位

类型：第一人称战术射击（FPS-Tactical）
引擎：Godot 4.7（Forward+ 渲染，Windows 下使用 D3D12 驱动）
物理：Jolt Physics
平台：PC（Windows优先）

模式：纯单机战役 + 可选挑战关卡
核心体验关键词：高速机动、战术决策、风格化视觉冲击、黑帮火并的紧张感

### 技术选型

引擎与运行时：Godot 4.7，Forward+ 渲染管线，Windows 下使用 D3D12；物理使用 Jolt Physics。

玩法语言：C#（.NET 8，工程 assembly 名 SuperHero）。业务逻辑写在 C# 里，.tscn 与自定义 Resource 只承担配置与视图。

美术资产：Blender 建模，通过 Blender MCP 操作 Blender；以 glTF 2.0（.glb）导出后导入 Godot。

版本管理：git，按里程碑分阶段提交，每阶段结束提交并推送到远程仓库。

### 1.2 设计支柱

"动如脱兔，静如处子"：高机动能力（蹬墙跑、翻越、滑铲）与战术慢节奏（掩体、瞄准、资源管理）形成张力，玩家需在"冲"与"蹲"之间做即时决策。

"一枪一世界"：低血量高伤害的写实向战斗，强调先手、爆头、掩体利用，鼓励玩家用机动性创造角度而非硬刚。

"漫画即界面"：美漫风不仅是美术，更渗透到UI、受击反馈、击杀提示、过场分镜中，让每一场战斗都像一页漫画。

"黄昏港口的压迫感"：场景氛围服务于叙事——腐败、危险、无处可逃
的边境地带。

### 目标玩家

喜爱《马克思·佩恩》《Superhot》《枪火重生》《使命召唤》战役模式与《镜之边缘》跑酷元素的玩家

对美漫视觉风格（如《罪恶之城》《蜘蛛侠：平行宇宙》）有审美偏好的玩家

## 游戏背景

### 2.1 世界观设定

时间：近未来（约2040年代），某东南亚/拉美风格的虚构港口城市——"圣米格尔港"（Puerto San Miguel）。

背景：圣米格尔港曾是繁荣的贸易枢纽，如今被三大黑帮势力割据：

"盐帮"（Los Sal）：控制码头与走私线，冷酷高效，装备精良。

"赤蛇会"（La Víbora Roja）：掌控毒品加工与分销，手段残忍，人数众多。

"铁锚帮"（Los Anclas）：本地码头工人组成的民兵式帮派，排外、凶悍，熟悉地形。

冲突导火索：一批新型合成毒品"黄昏（El Ocaso）"在港口中转，三方势力为争夺控制权爆发全面火并。主角作为前特种部队成员、现独立承包商（雇佣兵），受神秘客户委托潜入港口，任务层层揭开——最终发现"黄昏"背后牵扯到跨国财团与腐败的港口管理局。

### 2.2 叙事手法

美漫分镜过场：关键剧情以漫画分镜+旁白气泡呈现（参考《马克思·佩恩》的图形小说过场），降低动画成本同时强化风格。

环境叙事：涂鸦、尸体、毒品包装、无线电对话碎片构建世界。

主角独白：黑色电影式内心独白，配合漫画风字幕。

### 2.3 关卡叙事节奏

序章·潜入：夜雾中的码头外围，教学关（移动、翻越、潜行）。

第一章·盐帮码头：从吊塔顶一路下压到集装箱货场，首次大规模交火。

第二章·赤蛇工厂：毒品加工厂，垂直空间战斗（蹬墙跑核心关卡）。

第三章·铁锚据点：码头工人区，巷战与狙击。

终章·黄昏之海：港口管理局大楼与海上货轮，Boss战与抉择结局。

## 场景需求

### 3.1 港口场景——"黄昏码头"（核心关卡）

#### 3.1.1 空间结构（主线：从 42m 吊塔一路下压）

本章节的主线是纵向下行：玩家从港区西南侧的巨型吊塔顶部出发，沿塔身、脚手架、运输臂与集装箱屋顶逐层下压，落到地面货场后向北推进到栈桥与停机坪。

塔顶平台（Y=42m）：出生点、吊机驾驶室、护栏与第一场交火；视野最开阔，可俯瞰整个港区与海面。

脚手架层（Y=28–40m）：环绕塔身的层板、斜梯与安全网；包含第 1、2 处跳跃缺口（1.8m / 2.4m）。

运输臂与检修走道（Y=18–28m）：长条钢格栅走道，两侧悬空；包含第 3 处跳跃缺口（2.8m，需冲刺起跳）。

集装箱屋顶层（Y=6–18m）：3–4 层堆叠集装箱的顶部可行走；包含第 4、5 处跳跃缺口（3.2m 最难，以及 2.0m 缺口 + 6m 落差）。

地面货场（Y=0m）：仓库、码头空地、叉车与货车掩体；落地后的正面战场，也是全关交火密度最高的区域。

栈桥与停机坪：货场向北延伸的悬空栈桥；清场后直升机在此降落，作为收尾演出的舞台。

全关共五处跳跃缺口，每处下方 6–8m 设承接平台或安全网：跳跃失败只会落到下一层并受到摔伤，可以从该层继续向下，不必重开。

同一港口内的其它区域作为本章节的可探索区域或后续章节保留，不与吊塔主线冲突：

防波堤与灯塔：港口外围，序章的夜雾潜入与教学区，同时是远景中的灯塔剪影。

集装箱迷宫：地面货场东侧的多层堆叠区，地面阶段的跑酷与游击战场，可从货场直接进入。

仓库群：地面货场的室内 CQB 区域，与主线仓库连通。

海上货轮区：终章关卡，停泊在港口外侧，从塔顶即可望见其剪影。

港口管理局大楼：终章垂直战斗区，位于港区远端，在本章节中作为远景地标出现。

空间关系上，吊塔位于港区西南，主线一路向北：塔顶 → 塔身 → 集装箱屋顶 → 货场 → 仓库/集装箱迷宫 → 栈桥 → 停机坪；货轮与管理局大楼在本章节只作为远景与后续章节的入口。

#### 3.1.2 氛围与光照

时间：黄昏"魔幻时刻"（Magic Hour），太阳低角度贴近海平线。

主色调：暖黄、橙红、琥珀色，阴影处偏紫蓝（互补色对比）。

光源：低角度平行光（太阳）+ 码头钠灯（橙色点光源）+ 货轮航行灯（红绿点缀）+ 海面反射（高光闪烁）。

海面：辽阔、平静但带微波，反射夕阳形成金色光带；远处有货轮剪影与海鸥。

雾效：轻度体积雾，增强纵深与"黄昏雾气"感，同时优化远景。

粒子：海风扬起的灰尘、纸屑、码头煤烟、偶尔的海鸥。

#### 3.1.3 关键视觉锚点（Landmark）

巨大的橙色吊塔剪影（玩家出生的 42m 吊塔，全关最高点，回望时的导航参照）

灯塔（远处闪烁）

海平线上的落日（视觉焦点）

堆叠集装箱上的帮派涂鸦（美漫风，可做收集品/叙事）

## 美术风格

### 4.1 核心风格定义

"硬钢笔 + 明快色块"美漫风（Hard Ink + Flat Color Comic Style）

参考对象：
《蜘蛛侠：平行宇宙》（色彩与分镜）
《罪恶之城》（高对比黑白+单色点缀，用于特定桥段）
《无主之地》的描边+平涂（但更"漫画"而非"卡通"）
《Hi-Fi Rush》的动感漫画演出

### 4.2 视觉规则

#### 4.2.1 模型（低模 + 描边）

低多边形：硬边、块面化，强调剪影可读性。

描边（Outline）：通过反向法线外扩Shader或后处理边缘检测实现黑色钢笔线稿感，描边粗细可随距离/景深变化（近粗远细）。

表面处理：平涂色块（Flat Shading），减少渐变，用色阶分层（Posterize）表现光影，形成"漫画上色"感。

细节贴图：仅用少量手绘感贴图点缀（涂鸦、锈迹、弹孔），大面积保持纯色块。

#### 4.2.2 色彩系统

主色板：暖黄(#F2C14E)、橙红(#E4572E)、琥珀(#D98324)、深海蓝(#1B3A4B)、紫色阴影(#3D2C4A)。

高对比：角色与场景拉开明度/饱和度，敌人用醒目色（红、品红）标识，友军/中立用冷色。

阴影：不用纯黑，用深紫/深蓝（美漫习惯），增强色彩丰富度。

动态色块：受击、爆炸时叠加半调网点（Halftone）与速度线。

#### 4.2.3 特效（美漫化）

枪口火焰：手绘感锯齿形爆炸色块 + 白色核心。

弹着点：漫画式"POW!""BANG!"拟声词气泡（可开关）。

血液：红色平涂色块 + 网点，非写实喷溅。

受击反馈：屏幕边缘黑色钢笔线框闪烁 + 角色身上出现"X"眼或冲击线。

击杀：慢动作 + 分镜框 + 拟声词 + 角色剪影高亮。

速度线：蹬墙跑、滑铲时屏幕边缘出现放射状速度线。

#### 4.2.4 UI/HUD

漫画分格布局：生命值、弹药以"漫画面板"形式呈现（手绘边框、网点底纹）。

拟声词提示：换弹时"CLICK!"、低血量时心跳线+红色网点。

对话/独白：漫画气泡+手写体字体。

过场：静态漫画分镜 + 有限动画（镜头推移、局部动效）。

## 玩法系统

### 5.1 移动系统（高机动性）

基础：行走、冲刺、蹲伏、跳跃。

核心机动：
蹬墙跑（Wall Run）：沿集装箱/墙面横向或垂直跑动，可接跳跃。
翻越（Vault）：自动/手动翻越矮掩体、栏杆。
滑铲（Slide）：冲刺中下蹲，可开火。
攀爬抓取（Ledge Grab）：边缘悬挂、上翻。

设计原则：机动不消耗生命资源；若引入"体力"，只影响机动并快速回复，不涉及任何回血。开火/瞄准时降速，形成"动-静"节奏。

### 5.2 战斗系统（战术射击）

血量：低血量（如3-4枪毙命），依赖掩体与先手。

武器（按章节解锁，港口章节只有两类）：
序章与第一章（港口）：手枪、近战（枪托/刀）。本章武器池仅此两类，不出现冲锋枪、霰弹枪、狙击枪。
第二章·赤蛇工厂：解锁冲锋枪。
第三章·铁锚据点：解锁霰弹枪与狙击枪。
首个可玩原型阶段先实装手枪；近战（枪托/刀）作为港口章节的第二类武器随后补齐，后续枪械按章节逐步加入。

瞄准：腰射散布大，机瞄精准；爆头高伤。

掩体系统：贴掩体、盲射、探头射击。

子弹时间（可选）：闪避/击杀触发短暂慢动作，强化漫画演出（参考《马克思·佩恩》）。

敌人AI（三大帮派行为差异）：
盐帮：战术协同、交叉火力、依托掩体推进；对应已实现的"守卫"行为（保持 10–18m、掩体探头、点射）。
赤蛇会：人数多、打法疯，主动压上贴身压制；对应已实现的"街头枪手"行为（4–9m 斜向接近、短促连发）。
铁锚帮：本地码头工人，熟悉地形，善用吊机、货架与高处包抄；行为在后续章节扩展。
港口章节（序章与第一章）部署的是盐帮：已实现的"街头枪手 / 守卫"分别对应盐帮的"巡场打手"与"哨位枪手"，是同一势力的两种战斗角色；赤蛇会与铁锚帮在后续章节登场。

### 5.3 潜行与战术选择

潜行暗杀、环境击杀（吊货坠落、爆炸桶）。

警报系统：被发现后增援，鼓励"打了就跑"的游击。

### 5.4 成长与资源

简化成长：武器升级（瞄准镜、弹匣）、技能点（机动/战斗/生存三系）。

资源管理：只有弹药需要管理（弹匣容量、备弹、掉落补给）。生命值全程不可恢复——没有医疗包、没有自动回血、没有治疗类技能或道具；受伤只能靠掩体、走位与先手避免。技能树中的"生存"系只提供减伤、抗摔、更快的脱离等效果，不得包含任何回血。
